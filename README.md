# API cursos
API para gerenciamento de professores e cursos

## tecnologia
- Javasricpt
- node JS
- Mysql
- Express

## Endpoints
- `POST /professores` - Criar um professor
- `GET /professores` - Lista professores
- `POST / cursos` - Criar um curso
- `GET /cursos` - Lista cursos
- `DELETE /cursos/:id` - Deleta um curso por id
